# Cybersecurity Log Analysis Dashboard

### Overview

This project is a cybersecurity dashboard built with Python and Streamlit that analyzes log files and identifies suspicious activity.



### Features

* Upload log files
* Search and filter logs
* Threat scoring
* Error and warning detection
* Interactive visualizations



### Technologies Used

* Python
* Streamlit
* Pandas
* Plotly



### How to Run

Open PowerShell

Navigate to the project folder

Run:

streamlit run log\_dashboard.py
